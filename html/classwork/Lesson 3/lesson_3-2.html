[00:17] Типова структура вебсторінки складається з хедера (верхня частина), основного контенту та футера (нижня частина).

- [00:56] Раніше для таких секцій часто використовували `div` із класами (`header`, `main`, `footer`), але в HTML5 рекомендується застосовувати семантичні теги.

- [02:03] Тег `header` використовується для шапки сайту: логотипа, банера, навігації та іншої верхньої інформації.

- [02:30] Тег `nav` призначений для навігаційного меню сайту.

- [02:42] Тег `main` містить основний вміст сторінки.

- [02:48] Тег `section` використовується для логічно відокремлених секцій контенту.

- [02:54] Тег `article` підходить для самостійних блоків контенту або статей.

- [03:08] Тег `aside` застосовується для бічних блоків із додатковою інформацією.

- [03:21] Тег `footer` використовується для підвалу сайту.

- [03:31] Тег `address` містить фізичну або цифрову адресу та контактні дані.

- [04:03] Не можна довільно вигадувати власні HTML-теги — слід використовувати лише стандартизовані елементи.

- [04:18] `div` залишається корисним для групування елементів, які не мають конкретного семантичного призначення.

- [04:43] `div` часто використовують для об’єднання логотипа з підписом, груп іконок або кнопок для зручного розміщення та стилізації.

- [05:11] Якщо блок має чітке призначення, слід використовувати відповідний семантичний тег; якщо ні — `div`.

- [05:25] Семантичні теги покращують індексацію сторінки та допомагають браузерам і пошуковим системам краще розуміти структуру сайту.

- [05:37] Використання семантичних тегів корисне насамперед для браузерів і SEO, оскільки вони визначають роль кожної частини сторінки.
